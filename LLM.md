# nextjs-template

Starter template for Hanzo apps: Next.js 13 App Router + Radix UI + Tailwind CSS, dark mode via `next-themes`, Lucide icons. Scaffold with `npx create-next-app -e https://github.com/hanzoai/nextjs-template`.

## Structure
- `src/` — app code (App Directory, components, styles).
- `components.json` — shadcn/ui generator config.
- `tailwind.config.js`, `tsconfig.json`, `next.config.mjs` — toolchain config.

## Commands
- Dev: `pnpm dev`
- Build: `pnpm build`
- Typecheck: `pnpm tc`
